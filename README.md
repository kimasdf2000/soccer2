# ⚽ FIFA WORLD CUP 3D (Tablet & Web Edition)

Three.js + TypeScript + Vite 기반으로 구축된 **FIFA 스타일 3D 월드컵 웹 축구 게임**입니다. **Vercel**에 정적 배포하여 **태블릿(iPad, Galaxy Tab 등)** 및 PC 웹 브라우저에서 즉시 플레이할 수 있습니다.

---

## 🌟 주요 기능 (Key Features)

1. **월드컵 공인구 5종 선택 및 실시간 변경 (`src/entities/WorldCupBall.ts`)**
   - **2022 카타르 월드컵 - 알 리흘라 (Al Rihla)**: 올라운드 밸런스 & 스피드쉘 궤적
   - **2018 러시아 월드컵 - 텔스타 18 (Telstar 18)**: 정교한 패스 & 안정적 바운스
   - **2014 브라질 월드컵 - 브라주카 (Brazuca)**: 강력한 프리킥 감아차기(마그누스 커브) 특화
   - **2010 남아공 월드컵 - 자불라니 (Jabulani)**: 예측불허 무회전(Knuckleball) & 급격한 낙차 특화
   - **2002 한·일 월드컵 - 피버노바 (Fevernova)**: 폭발적인 중거리 슈팅 파워 특화
   - 매치 시작 로비뿐 아니라 경기 중 상단 `⚽ 공인구 변경` 버튼으로 실시간 교체가 가능합니다.

2. **심판(Referee) 3D 캐릭터 및 원거리 추적 AI (`src/entities/Referee.ts`)**
   - 형광 옐로/블랙 심판복과 호루라기, 머리 위 `👨‍⚖️ REF (심판)` 배지를 가진 심판이 경기장 내에 상주합니다.
   - **원거리 추적 알고리즘**: 공과 선수들의 패스/이동 동선을 방해하지 않도록 반발력 벡터를 계산하여 약 **10m ~ 13.5m** 대각선 안전 거리를 유지하며 따라다닙니다.
   - **파울 & 카드 선언 연출**: 파울 발생 시 즉시 호루라기를 불며 반칙 선수 앞으로 달려가 **3D 옐로카드(`🟨`)** 또는 **3D 레드카드(`🟥`)**를 머리 위로 높이 들어 올립니다.

3. **파울 규칙 및 옐로카드 / 레드카드 퇴장 시스템 (`src/Game.ts`)**
   - 수비 중 슬라이딩 태클 시 공을 먼저 정확히 건드리면 **클린 태클(`CLEAN TACKLE!`)**, 공을 건드리지 못하고 상대 선수를 가격하거나 후방 백태클을 범하면 **파울 선언(`FOUL!`)**이 이루어집니다.
   - **옐로카드 2회 누적 시 자동 레드카드(`🟨➡️🟥`)** 또는 위험한 백태클 시 **다이렉트 레드카드(`🟥`)**가 선언되며, 퇴장당한 선수는 실제 경기장에서 제거되어 남은 경기를 수적 열세로 진행합니다.

4. **프리킥(Free Kick) & 페널티킥(Penalty Kick) 세트피스**
   - **프리킥**: 페널티 박스 바깥 파울 시 공과 골대 사이 9.15m 거리에 3~4인 **수비벽(Defensive Wall)**이 세워지고, 키커 후방 3인칭 시점과 **3D 실시간 예상 궤적 점선 아크(마그누스 커브 반영)**가 표시됩니다. 슛 순간 수비벽이 점프합니다.
   - **페널티킥**: 페널티 박스 안쪽 파울 시 11m 페널티 스팟에서 키커 vs 골키퍼 1:1 대결이 펼쳐집니다. 골문 코너 조준(좌/우 상단 사각, 하단 구석, 파넨카 칩슛) 및 수비 시 골키퍼 다이빙 방향 선택이 가능합니다.

5. **태블릿 맞춤형 듀얼 터치 컨트롤 (`src/systems/TouchController.ts`)**
   - **좌측 하단**: 360° 멀티터치 가상 조이스틱 (이동 및 세트피스 궤적 조준)
   - **우측 하단**: 공격/수비/세트피스 상황에 따라 자동 변환되는 액션 버튼 패드
     - 공격 시: `슛 (SHOOT - 홀드 게이지)`, `패스 (PASS)`, `스루 패스 (THROUGH)`, `질주 (SPRINT)`
     - 수비 시: `슬라이딩 태클 (SLIDE TACKLE)`, `압박/견제 (PRESS)`, `선수 전환 (SWITCH)`, `질주 (SPRINT)`

## 🚀 로컬 실행 및 Vercel 배포 방법

### 1. 로컬 개발 서버 실행
```bash
npm install
npm run dev
```

### 2. 프로덕션 빌드 테스트
```bash
npm run build
npm run preview
```

### 3. Vercel 배포
프로젝트 루트에 `vercel.json`이 구성되어 있으므로 GitHub 저장소 연결 또는 Vercel CLI로 즉시 배포됩니다:
```bash
npx vercel --prod
```
배포된 Vercel URL에 태블릿 브라우저(Safari / Chrome)로 접속한 뒤 우측 상단 `⛶` 전체화면 버튼을 누르면 쾌적하게 플레이할 수 있습니다.
